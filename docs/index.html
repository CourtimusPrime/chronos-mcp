Features

Everything agents need, nothing they don't

Chronos stays on your machine. No cloud proxy, no external service — just a fast local database your agents query directly.

📬

Multi-account Gmail sync

Register any number of Gmail accounts under one daemon. All threads and messages land in one database.

📅

Google Calendar sync

Events, attendees, and recurrence rules synced incrementally. Full-text search across event titles and descriptions.

🔍

Full-text search (FTS5)

SQLite FTS5 indexes on messages and events. Sub-millisecond local search, no external search service needed.

🤖

MCP server

Exposes all data at localhost:7071/sse. Drop the config snippet into Claude, Cursor, or any MCP-compatible agent.

🗄️

Raw SQL access

Read-only SQL interface via POST /v1/query. Query the database directly from any HTTP client or agent tool.

⚡

Incremental sync

Gmail historyId and Calendar syncToken mean only deltas are fetched — fast, battery-friendly, and quota-safe.

Quickstart

Up and running in minutes

You need a Google Cloud project with Gmail and Calendar APIs enabled, and an OAuth client credentials JSON (Desktop app type).

Install

pipx install chronos-agent-inbox
or clone the repo and pip install -e .

Stage credentials

chronos --use /path/to/credentials.json
Points Chronos at your OAuth client JSON from Google Cloud Console.

Add an account

chronos --add personal
Opens the browser for OAuth2 consent. Repeat for as many accounts as you need.

Start the daemon

chronos --start
HTTP API on :7070, MCP/SSE on :7071. Syncs run in the background.

Agent integration

Add Chronos to your MCP client

Paste this into your Claude, Cursor, or other MCP-compatible agent configuration. Make sure chronos --start is running first.

claude_desktop_config.json / .cursor/mcp.json 
// Claude Desktop — ~/Library/Application Support/Claude/claude_desktop_config.json
{
  "mcpServers": {
    "chronos": {
      "url": "http://localhost:7071/sse",
      "transport": "sse"
    }
  }
}
CLI Reference

All commands at a glance

Run chronos --help for full Google Cloud Console setup instructions.

CommandDescription
--use CREDENTIALS_PATHStage an OAuth credentials JSON for the next --add call
--add ALIASRegister a new account (opens browser for consent)
--remove ALIASRemove an account and its data
--listList all registered accounts
--test ALIASVerify account tokens are valid
--start [--http-port N] [--mcp-port N]Start the sync daemon
--stopClean shutdown — preserves synced data
--statusShow sync status for all accounts
--sync [ALIAS] [--type full|incremental]Trigger a manual sync

Note: Ctrl+C during --start wipes synced data (emails, events) but preserves accounts. Use chronos --stop from another terminal for a safe shutdown.
